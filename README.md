# Hashcat Tables Collection
Lastest Hashcat tables used in attack mode 5 for password cracking. Please read [this doc](https://github.com/hashcat/hashcat/blob/master/docs/hashcat-table.md) to understand how table attacks work in Hashcat. 

> [!NOTE]
> ***This should not be confused with Hashcat rules. A collection of these can be found [here](https://github.com/ibnaleem/rules).***
